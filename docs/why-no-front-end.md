# Why no front end

The database stores the part revisions, component relationships and review decisions. An agent reads and changes those records through a single CLI. Read-only HTML shows the week and produces the handover paperwork.

This base does not provide CAD authoring, CAD previews, live co-editing, offline mobile capture, drag-and-drop BOM editing, binary file versioning or authenticated approval screens. Those require separate applications and integrations. Evidence references do not copy or verify the files. Enterprise DNA can scope the required screens, file storage and integrations around your process.

The private reports have no action buttons and no server. Review before sharing. They show the records as they stood when generated, not a live or certified design state.
